# Tint approval change in build 3.3.0

When a Buyer submits an order containing any tinted line, the order must enter **Awaiting approval**, including an order at or below EUR 5,000 net. The rule applies whether the tint was present when the order was created or added while editing a saved draft. Existing pack-size restrictions and the high-value approval rule continue to apply.

Use the same order value, pack sizes, tint, user role and submitted action when comparing the two starting states. Record your predictions and the states you actually see separately.
