# A buyer needs a custom colour on site

**Proposed story for review.** A buyer wants to choose a custom colour and request Express delivery for an urgent site order. A product owner has sent this draft for feedback before implementation.

1. Every order line should accept a custom colour code regardless of pack size.
2. The Express option should appear for any product in the catalog.
3. Orders worth more than EUR 5,000 should require approval.

Compare the wording with the currently approved product rules. Record the questions you would take back to the owner.
